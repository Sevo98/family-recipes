# Семейное меню на 30 дней

Сайт: https://sevo98.github.io/family-recipes/

Меню на двоих, подробные рецепты, отдельная категория салатов, покупки на месяц, неделю и день. GitHub Pages: main, корень.

## Телефон и офлайн

Android: меню браузера → «Установить приложение». iPhone: Safari → «Поделиться» → «На экран Домой». После первого открытия онлайн приложение сохраняет офлайн-копию. После обновления закройте все его окна и откройте снова, если видите старую версию.

## База: рецепты и продукты

Каталог хранится в Supabase:

| Таблица | Назначение |
|--------|------------|
| `products` | Продукты (название, единица, группа закупок, категория, опционально ккал/100 г) |
| `recipes` | Рецепты (приём пищи, шаги, дни меню, описание, счётчик лайков) |
| `recipe_ingredients` | Состав рецепта: продукт + количество + порядок |
| `recipe_likes` | Лайки по `device_id` (без входа) |
| `family_shared_state` | Общий список покупок / настройки (как раньше) |

Миграции: [`supabase/migrations/001_catalog.sql`](supabase/migrations/001_catalog.sql), сид: [`supabase/migrations/002_seed_from_menu.sql`](supabase/migrations/002_seed_from_menu.sql) (пересборка: `python scripts/generate_seed_sql.py`).

**Один раз** выполните оба SQL-файла в Supabase → SQL Editor (сначала `001`, затем `002`). После этого сайт подхватит каталог из базы. Если таблицы уже есть, но пустые, клиент сам засеет данные из `menu-data.js` при первом успешном подключении.

Офлайн и до миграции сайт работает на встроенном снимке `menu-data.js` и кэше `localStorage` (`meal-plan-catalog-v1`).

Лайки, добавление и правка рецептов/продуктов доступны анонимно — как и общий список покупок. Любой посетитель публичного сайта может менять каталог.

## Сохранения покупок

Без входа галочки, порции, перекусы и выбор салатов синхронизируются через `family_shared_state`. Отправка после изменения и каждые 15 секунд. Офлайн-изменения уходят после подключения. При конфликте одной позиции побеждает последнее отправленное изменение.

Supabase project: `fckkbcxaghwuyapszwap`. RLS разрешает общий анонимный доступ. Данные не следует считать приватными. В браузере используется только публичный publishable key. Запросы базы не кешируются service worker.

Входа и писем нет.

## Обновление

Публикуйте весь комплект файлов. При изменении кешируемых ресурсов увеличивайте версию `CACHE` в `sw.js`. Supabase закреплён на версии 2.117.2 и сохранён локально; источник и SHA-256 — в `vendor-lock.json`, лицензия — в `SUPABASE-LICENSE.txt`.
