# Меню на 30 дней

Статическая страница для двоих: меню, подробные рецепты, отдельная категория салатов и интерактивные покупки на месяц, неделю и день.

## GitHub Pages

В настройках репозитория: **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**.

Главная страница — `index.html`. Сборка, сервер и база данных не требуются. Файл `.nojekyll` отключает обработку Jekyll.

## Использование

Галочки покупок, размер порций и выбранные салаты сохраняются локально в браузере. Они не передаются на GitHub и не синхронизируются между устройствами. Отметки из локального HTML-файла не перенесутся на адрес сайта автоматически.

Чтобы обновить сайт, замените `index.html` новой версией и сохраните изменения в публикуемой ветке.
