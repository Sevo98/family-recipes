# Семейное меню на 30 дней

Сайт: https://sevo98.github.io/family-recipes/

Меню на двоих, подробные рецепты, отдельная категория салатов, покупки на месяц, неделю и день. GitHub Pages: main, корень.

## Телефон и офлайн

Android: меню браузера → «Установить приложение». iPhone: Safari → «Поделиться» → «На экран Домой». После первого открытия онлайн приложение сохраняет офлайн-копию. После обновления закройте все его окна и откройте снова, если видите старую версию.

## Сохранения

Без входа данные хранятся в общем списке: галочки, порции, перекусы и выбор салатов синхронизируются между всеми устройствами и посетителями сайта. Отправка происходит после изменения и каждые 15 секунд, пока страница открыта. Офлайн-изменения отправляются после подключения. При конфликте одной позиции побеждает последнее отправленное изменение. Локальные галочки первого устройства переносятся в пустой список.

Supabase project: fckkbcxaghwuyapszwap. Таблица public.family_shared_state защищена RLS, но разрешает общий анонимный доступ для чтения и записи. Любой посетитель опубликованного сайта сможет увидеть и поменять сохранения. Данные не следует считать приватными. В браузере используется только публичный publishable key. Запросы базы не кешируются service worker.

Входа и писем нет.

## Обновление

Публикуйте весь комплект файлов. При изменении кешируемых ресурсов увеличивайте версию CACHE в sw.js. Supabase закреплён на версии 2.117.2 и сохранён локально; источник и SHA-256 — в vendor-lock.json, лицензия — в SUPABASE-LICENSE.txt.
