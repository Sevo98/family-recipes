# Семейное меню на 30 дней

Сайт: https://sevo98.github.io/family-recipes/

Меню на двоих, подробные рецепты, отдельная категория салатов, покупки на месяц, неделю и день. GitHub Pages: main, корень.

## Телефон и офлайн

Android: меню браузера → «Установить приложение». iPhone: Safari → «Поделиться» → «На экран Домой». После первого открытия онлайн приложение сохраняет офлайн-копию. После обновления закройте все его окна и откройте снова, если видите старую версию.

## Сохранения

Без входа данные остаются в браузере. После входа под одним email на нескольких устройствах синхронизируются галочки, порции, перекусы и выбор салатов. Отправка происходит после изменения и каждые 15 секунд, пока страница открыта. Офлайн-изменения отправляются после подключения. При конфликте одной позиции побеждает последнее отправленное изменение. Локальные галочки переносятся при первом входе, если облачное сохранение ещё пустое.

Supabase project: fckkbcxaghwuyapszwap. Таблица public.recipe_state, ключ (user_id,key), доступ защищён RLS по auth.uid(). В браузере используется только публичный publishable key. Запросы авторизации и базы не кешируются service worker.

Вход по одноразовой ссылке Supabase. Стандартная отправка писем ограничена адресами участников организации Supabase: используйте email владельца проекта на обоих устройствах. Для сторонних пользователей настройте собственный SMTP. В установленном приложении можно вставить адрес кнопки из письма в раздел «Войти внутри установленного приложения».

## Обновление

Публикуйте весь комплект файлов. При изменении кешируемых ресурсов увеличивайте версию CACHE в sw.js. Supabase закреплён на версии 2.117.2 и сохранён локально; источник и SHA-256 — в vendor-lock.json, лицензия — в SUPABASE-LICENSE.txt.
